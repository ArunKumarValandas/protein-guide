# 🏗 Architecture

```
React UI
    │
    ▼
Visualizer Components
    │
    ▼
Algorithm Frame Generator
    │
    ▼
Playback Store (Zustand)
    │
    ▼
Animation Engine
```

Algorithms generate visualization frames. Each frame stores the current state, highlights, statistics, and explanation. The playback engine powers play, pause, reset, step forward, step backward, speed control, and completion tracking.
